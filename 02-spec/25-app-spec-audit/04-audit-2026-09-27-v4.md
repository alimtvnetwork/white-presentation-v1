## 3. Root Cause Analysis: Mistakes & Omissions Disclosure

During initial delivery of the webcam specification, the agent mistakenly implemented only the camera-specific hotkeys (`I`, `O`, `E`) while omitting the core presentation deck shortcuts defined in `global-ppt-v1` (`shortcuts.ts`):
- `F` / `f` (Presentation Fullscreen) was only available via mouse click on the dock.
- `G` / `g` (Slide Overview Grid) was completely missing.
- `T` / `t` (Cycle Theme) was missing.
- `M` / `m` (Mute Audio) was missing.
- `?` / `/` (Keyboard Shortcuts Map) was missing.
- `Home` / `End` (First / Last Slide Jump) was missing.
- `1`–`5` (Direct Theme Palette Jump) was not hooked up.

**Remediation:** Full parity with `global-ppt-v1` has been engineered via `useDeckShortcuts.ts`, `KeyboardShortcutsModal.tsx`, and `OverviewGridModal.tsx`, keeping all component files strictly $\le 100$ lines.
